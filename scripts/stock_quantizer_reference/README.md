# Stock Quantizer frozen reference declaration

This independently written acceptance derives from Fundamental `10dd0160c664770910e5584b7b00498cc48d9ddd/src/Quantizer.cpp` (SHA-256 `811ba0af2e76f920b9748d87dcfd30144764c10cd319a5f101c9e6696e1c02ca`) and genuine Rack SDK 2.6.6 headers. It does not inspect or reproduce the new Rust quantizer. The runner must execute the actual pinned class and actual production probe, retain their source/build closure, and retain failures. This directory does not assert that a comparison has run or passed.

`acceptance.json` defines the 24-input/45-output wire and zero-tolerance gates. `fixtures.py` generates only inputs and a small set of independently hand-derived anchors, never a quantization lookup algorithm. `verify.py` streams both actual traces and verifies exact binary32 meaningful fields plus independent invariants. `fixtures.json` freezes input hashes, all case offsets/anchors, and the acceptance, generator, validator and README hashes. The five files are immutable after the initial freeze; the manifest's own SHA is recorded externally by the runner.

```sh
python3 scripts/stock_quantizer_reference/fixtures.py --freeze
python3 scripts/stock_quantizer_reference/fixtures.py --check-fixtures
python3 scripts/stock_quantizer_reference/verify.py --self-test
```

`--freeze` exclusively creates the manifest and refuses to overwrite one. `check_declaration()` recomputes its entire input/schema declaration. The runner can import `cases(rate,a)`, `rows(rate,a)` (yielding case name, frame index, 24 fields), `fixture_text(rate,a)`, and corresponding `safety_cases`, `safety_rows`, `safety_fixture_text`. It may materialize one rate's input string at a time; validation streams rows and keeps at most 16 detailed failures. `validate(rate,a,phase,input_path,sdk_trace_path_or_None,rust_trace_path)` returns a JSON-serializable report; `phase` is `reference` or `safety`. Paths contain uncompressed whitespace-separated text. The runner should retain compressed traces and record both compressed and uncompressed hashes; no numerical rows may be skipped.

The main matrix loads all 4096 enabled-note masks using the actual JSON loader. For every mask it probes all 24 half-semitone ranges at octave zero and minus one: interior, nominal boundary and adjacent f32 values, and the actual adjacent-f32 input pair bracketing the multiply/add threshold. Voice packing avoids redundant timing loops. Each rate has 89,161 reference frames in 4,544 cases and 105 safety frames in 15 cases (267,483 reference plus 315 safety frames total). Offsets, further octaves, integer-domain endpoints, widths and consumer states add targeted rows. Hand anchors expose C/D's delayed gap transition at 0.125 V and its next-C transition at 0.625 V, including their negative-octave counterparts; this source behavior differs from nearest continuous-pitch selection.

Source `playingNotes` is uninitialized before the first normal process. The SDK adapter must not read it then. A derived validity flag and zero wire sentinel describe that lifetime, not source memory contents. Afterwards the twelve actual booleans are compared, including replacement when width shrinks and updates while output is disconnected. Quantizer declares `NUM_LIGHTS=0`; these keyboard booleans are not an invented LED array. Bypass preserves them while the actual SDK bypass route passes raw CV. Configuration load/reset/rotation still applies when bypassed.

The processor's connected/disconnected behavior must be implemented inside production and exercised directly, never manufactured by changing emitted counts. This class-level qualification does not establish the public graph's cable/tap consumer delivery; root-owned host tests cover that separately. Inactive SDK output storage is not compared, but public Rust padding must be positive zero. Normal input padding is positive zero. No poisoned inactive-storage parity is implied.

Normal inputs keep the actual float-to-int and subsequent signed-int arithmetic defined. Merely fitting `floor(pitch*24)` in i32 is insufficient: its Euclidean quotient times 24 must also fit. The safe mathematical lower bound is -2147483640, with actual f32 endpoint -2147483520 exercised. Values outside this domain, NaN and infinities belong only to Rust safety cases. Unbypassed safety processing must remain finite under the declared saturating extension; raw bypass intentionally preserves active NaN/Inf instead. These rows do not claim C++ parity in undefined source domains.

Acceptance is exact across the entire bounded matrix. It does not claim exhaustive floating-point, SDK RNG-stream, malformed nonboolean JSON, full Rack engine, device, or native-visual equivalence. Randomize's possible masks are exhausted numerically; public randomize/undo, UI Initialize parameter reset, serialization and keyboard gestures remain host tests. Any future declaration correction must retain this declaration and its original result and use an explicitly versioned erratum.
