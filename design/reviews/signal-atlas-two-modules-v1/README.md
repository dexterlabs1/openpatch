## Actual module contracts

- **ADSR** maps to `adsr`: attack, decay, sustain and release; gate/retrigger inputs and envelope output. Time controls span 1 ms–10 s; sustain spans 0–100% of 10 V. Gate high advances Attack → Decay → Sustain, gate low releases; retrigger restarts Attack while gated. Miniature symbols describe rising, falling, held and release stages. The main plot is a continuous-time configured RC guide: attack targets 12 V and reaches 10 V at the selected time; decay/release use 99% settling times. It is not a sampled Rust-engine waveform or hardware measurement. Stage LEDs are intentionally inactive without engine telemetry.
- **Ladder** maps to `ladder_vcf`: pole frequency 20 Hz–18 kHz at 48 kHz, resonance 0–110%, input drive 0–4×; signal and 1 V/oct cutoff inputs, low-pass output. Four serial stages and negative feedback represent the existing model. The static zero-CV plot uses the model's small-signal transfer `drive / ((1 + j f/fc)^4 + 4 resonance)`; it does not depict the nonlinear output spectrum. At resonance ≥100% the display identifies the oscillation region, where the linearized equilibrium curve is not a stable live response. Pole frequency is not a −3 dB cutoff. Lower sample rates impose the engine's additional frequency cap.

Contracts were checked against `crates/openpatch-core/src/lib.rs`, `analog.rs` and `ladder.rs`. No engine code changed.

## Interaction and validation

Drag vertically; Ctrl/⌘ gives fine control. Arrow keys adjust, Shift increases the step, Home/End reach endpoints, double-click resets a knob. Click a numeric readout or press Enter on a knob to type in seconds, Hz, ratio or gain as labeled. Reset restores defaults; light/dark room changes the presentation. Both thumbnail and full-size SVGs are generated by the same function and track the same values.

Headless Chrome verified font loading, drag, keyboard endpoints, numeric entry, reset, synchronized plot paths, oscillation-region labeling, dark-room state, narrow layout and absence of runtime exceptions. Local evidence: `native-test-output/two-module-review/checks.json`. This does not establish native integration, live audio behavior or hardware fidelity.

## Native implementation

`crates/openpatch-desktop/src/atlas_voice_panel.rs` implements the approved layout in egui primitives. The interactive rack and module browser use the same native renderer. Existing HP widths, parameter and port identities remain stable; the three sockets move to one common bottom row. Time/frequency knobs now use geometric travel; stored values and DSP remain unchanged. Numeric entry uses seconds, Hz, percent for sustain/resonance, and gain for drive. Existing gesture undo, keyboard/fine edits, context menus and MCP construction anchors are retained.

The native configured envelope explicitly samples stage boundaries so even a short attack is represented. Filter frequency labels and plot use the effective sample-rate cap. Passive ADSR stage lenses stay inactive because this legacy module exposes no stage telemetry; port signal lights retain their existing real engine data. Native captures are headless egui mesh renders, not window/device validation. The installed 0.2.5 build 7 is unchanged.

[Native rack/browser capture](native-preview.png): real egui meshes at full and thumbnail sizes. Final macOS ARM desktop regression: **1,081 passed, 4 ignored**; strict desktop Clippy and formatting checks passed. Light/dark native captures were inspected. The regression also caught an earlier quantizer animation assertion that still expected a fader and a small pre-existing resonator axis-label overlap; the assertion and spacing were corrected.

## Analog voice continuation

[Native VCO, Ladder, ADSR and OTA VCA](native-analog-voice.png) shows the four-module voice and matching thumbnails. The new VCO guide illustrates the nominal ±5 V saw/pulse before BLEP correction, with zero-CV cycle period; width applies only to Pulse. Frequency uses geometric travel and pulse-width numeric entry uses percent. The OTA guide is the static matched-pair transfer at 25°C and CV 10 V, before oversampling-filter dynamics; a focused test compares it with the settled actual engine at 15 input/gain combinations. CV clamps to 0–10 V and defaults to 10 V when unpatched.

The new layouts preserve the VCO's 14 HP and VCA's 10 HP widths. All three ports move to the common lower row. The narrower VCA has a larger main knob and readable minimum hardware/type sizes. Native light/dark meshes were inspected. No application was installed.
