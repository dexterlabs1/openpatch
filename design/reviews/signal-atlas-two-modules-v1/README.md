## Actual module contracts

- **ADSR** maps to `adsr`: attack, decay, sustain and release; gate/retrigger inputs and envelope output. Time controls span 1 ms–10 s; sustain spans 0–100% of 10 V. Gate high advances Attack → Decay → Sustain, gate low releases; retrigger restarts Attack while gated. Miniature symbols describe rising, falling, held and release stages. The main plot is a continuous-time configured RC guide: attack targets 12 V and reaches 10 V at the selected time; decay/release use 99% settling times. It is not a sampled Rust-engine waveform or hardware measurement. Stage LEDs are intentionally inactive without engine telemetry.
- **Ladder** maps to `ladder_vcf`: pole frequency 20 Hz–18 kHz at 48 kHz, resonance 0–110%, input drive 0–4×; signal and 1 V/oct cutoff inputs, low-pass output. Four serial stages and negative feedback represent the existing model. The static zero-CV plot uses the model's small-signal transfer `drive / ((1 + j f/fc)^4 + 4 resonance)`; it does not depict the nonlinear output spectrum. At resonance ≥100% the display identifies the oscillation region, where the linearized equilibrium curve is not a stable live response. Pole frequency is not a −3 dB cutoff. Lower sample rates impose the engine's additional frequency cap.

Contracts were checked against `crates/openpatch-core/src/lib.rs`, `analog.rs` and `ladder.rs`. No engine code changed.

## Interaction and validation

Drag vertically; Ctrl/⌘ gives fine control. Arrow keys adjust, Shift increases the step, Home/End reach endpoints, double-click resets a knob. Click a numeric readout or press Enter on a knob to type in seconds, Hz, ratio or gain as labeled. Reset restores defaults; light/dark room changes the presentation. Both thumbnail and full-size SVGs are generated by the same function and track the same values.

Headless Chrome verified font loading, drag, keyboard endpoints, numeric entry, reset, synchronized plot paths, oscillation-region labeling, dark-room state, narrow layout and absence of runtime exceptions.
