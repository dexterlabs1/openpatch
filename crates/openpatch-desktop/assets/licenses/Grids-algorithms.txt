Modifications: per-instance Rust adaptation of the original Grids integer
PatternGenerator, Clock, 25 map nodes, Euclidean/tempo tables and explicit
16-bit avrlib LFSR. OpenPatch supplies native fixed 8 kHz scheduling, voltage/CV
mapping, Schmitt input, ordered fixed-capacity event capture, guarded tap actions,
saved controls, lifecycle and shared panel/telemetry policies. Reset quirks and
source-defined arithmetic remain declared contracts. Physical board timer,
ADC/button/EEPROM scheduling, hardware circuitry, artwork and logos are excluded.
No AVR electrical or CPU timing equivalence is claimed.

Corresponding source is included at crates/openpatch-core/src/rhythm_terrain.rs,
crates/openpatch-core/src/rhythm_terrain/ and scripts/grids_reference/, with pinned
source hashes and a retrieval script. The reference host overlay selects original
portable arithmetic and excludes only the proven-unused, uncompilable U24Sub
fallback; original sources, hashes and the exact overlay diff are retained.
See docs/RHYTHM_TERRAIN.md for source/native boundaries and qualification scope.
