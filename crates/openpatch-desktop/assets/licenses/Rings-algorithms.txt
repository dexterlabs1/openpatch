String Field / Rings source adaptation
======================================

Covered OpenPatch files: openpatch-core/src/string_field/kernel.rs and
openpatch-core/src/string_field/kernel/*.rs.

Adapted into Rust from Rings and stmlib by Emilie Gillet:
eurorack f4cfa7697095a28d292bff758beb51deb49b5a86
stmlib e3bd7c9cc00e4364166f9905c0509b6ffd0535ec
https://github.com/pichenettes/eurorack/tree/f4cfa7697095a28d292bff758beb51deb49b5a86/rings
https://github.com/pichenettes/stmlib/tree/e3bd7c9cc00e4364166f9905c0509b6ffd0535ec

Modified Rust source (part and voice allocation, note filter, strummer and
onset detector, plucker, modal resonator, Karplus-Strong string with
dispersion, FM voice and follower, FX engine and reverb, limiter, and the
noise gate and output conversion of the firmware audio callback) and
generated bit-preserving lookup tables, with an original OpenPatch native
adapter, 48 kHz rate bridge and panel. No Mutable Instruments artwork, logo,
analog hardware, codec/CV calibration, settings storage, firmware UI or the
easter-egg string synthesizer is incorporated. Source inventory and file
hashes: scripts/rings_reference/source_manifest.json. The voltage scaling, CV
mapping, jack normalization and host-rate resampling are explicit OpenPatch
adaptations; this does not claim complete firmware or hardware identity.
